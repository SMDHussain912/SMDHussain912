## About me

I'm a Computer Engineering diploma student at Andhra Polytechnic, Kakinada, and I like building real things across many areas of software: full-stack web apps, game engines, local AI tools and mobile apps. I learn best by shipping projects.

At **National Informatics Centre (NIC), Collector Office, Kakinada**, I'm doing a web development internship where I built the entire backend of **PM-SETU Andhra Pradesh**, a web platform supporting the state's ITI upgradation scheme.

I'm currently open to **software and web development internships**.

## What I'm working on

- 🏛️ **PM-SETU Andhra Pradesh**: backend (Node.js, Express, TypeScript, Prisma, PostgreSQL) built during my NIC internship
- 🎮 **ArcEngine**: an open-source game engine in C++ for Linux, with Android planned
- 🗣️ **MiraV2**: a local-first voice assistant for Linux with an on-device intent model
- 🎓 **UniSphere**: a learning and career platform, being rebuilt from scratch with an Android app

| Project | What it is | Tech |

| [**PM-SETU-Backend**](https://github.com/SMDHussain912/PM-SETU-Backend) | Backend for the PM-SETU Andhra Pradesh platform: REST APIs documented with Swagger, a 19-table PostgreSQL schema, Dockerized. Built with a teammate who made the frontend ([PM-SETU-Frontend](https://github.com/SMDHussain912/PM-SETU-Frontend)). | TypeScript, Node.js, Express, Prisma, PostgreSQL, Docker |

OpenGL renderer, scene and entity system, Box2D physics, YAML scene files, editor and automated tests. Lua scripting, 3D and Android export are on the roadmap. | C++17, OpenGL, Box2D, CMake |
| [**MiraV2**](https://github.com/SMDHussain912/MiraV2) | A modular, local-first voice assistant for Linux. Speech is transcribed on-device with whisper.cpp, then a small intent model (PyTorch, exported to int8 ONNX) decides what to do, and it asks instead of acting when unsure. | C++, Python, PyTorch, ONNX, whisper.cpp, PipeWire |
| [**UniSphere**](https://github.com/SMDHussain912/UniSphere) | A platform to learn programming, practice, find jobs and internships, with learning games and chat. | JavaScript, React, Node.js |
